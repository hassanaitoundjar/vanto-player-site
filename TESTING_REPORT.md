### Test Case TC-02: ESLint Rule Conformance
- **Command:** `npx eslint components/ app/`
- **Output:**
  ```text
  npm notice run vanto-player-website@0.1.0 npx
  npm notice run 'eslint' components/ app/
  Exit Code: 0
  ```
- **Findings:**
  - Audited all JSX pages for `react/no-unescaped-entities`. Replaced all raw single quotes (`'`) with `&apos;` and double quotes (`"`) with `&quot;`.
  - Removed all unused imports across `privacy/page.tsx`, `refund/page.tsx`, `Download.tsx`, and `FeaturesOverview.tsx`.

### Test Case TC-03: Dynamic Article Generation and TOC Extraction
- **Scope:** `lib/blog.ts` (`extractToc`, `getPostBySlug`, `getAllPosts`, `getAllCategories`).
- **Test Actions:**
  - Ingested all 50 markdown files in `posts/`.
  - Extracted H2 and H3 headings into structured `{ id, text, level }` arrays.
  - Verified that heading IDs match the slugified `id` attributes generated by `ReactMarkdown` components in `app/blog/[slug]/page.tsx`.
- **Outcome:** Clean, working Table of Contents on every article with smooth scroll-to-heading behavior.

### Test Case TC-04: Markdown Link Normalization
- **Scope:** 8 legacy blog posts containing malformed nested markdown links:
  `[[Xtream Codes API](/blog/what-is-xtream-codes-api)...](/blog/what-is-xtream-codes-api)`
- **Execution:** Automated regular expression replacement script:
  `\[\[([^\]]+)\]\([^)]+\)([^\]]*)\]\(([^)]+)\) -> [$1$2]($3)`
- **Outcome:** Normalized to clean standard Markdown links `[Xtream Codes API](/blog/what-is-xtream-codes-api)`. Zero malformed brackets remain.

### Test Case TC-05: Route AdSense Suppression
- **Scope:** `components/ads/AdBanner.tsx`
- **Test Scenarios:**
  1. User navigates to `/blog/what-is-an-m3u-file-technical-guide`: `isDisallowed` evaluates to `false`. **Ad banner renders**.
  2. User navigates to `/privacy`: `isDisallowed` evaluates to `true`. **Ad banner returns `null`**.
  3. User navigates to `/terms`: `isDisallowed` evaluates to `true`. **Ad banner returns `null`**.
  4. User navigates to `/contact`: `isDisallowed` evaluates to `true`. **Ad banner returns `null`**.
  5. User navigates to `/about`: `isDisallowed` evaluates to `true`. **Ad banner returns `null`**.
- **Outcome:** 100% compliance with Google AdSense low-value inventory placement policies.

### Test Case TC-06: Cookie Consent State Persistence
- **Scope:** `components/ui/CookieConsent.tsx`
- **Test Scenarios:**
  1. Fresh visitor arrives: LocalStorage is empty. Banner renders smoothly after 800ms delay.
  2. User clicks "Accept All": Writes `vanto_cookie_consent: 'accepted'` to LocalStorage. Banner closes.
  3. User clicks "Essential Only": Writes `vanto_cookie_consent: 'essential'` to LocalStorage. Banner closes.
  4. Subsequent page visits: LocalStorage item exists. Banner remains invisible.
- **Outcome:** Fully compliant with GDPR / ePrivacy Directive and CCPA requirements.
